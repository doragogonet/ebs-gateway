⑩非同期INVENRTOY送信
----------------------------------------------------------
{"command": "Start_Inventory_Thread","modelName":"FX9600","params": {"timeout_ms": 3000}}

----------------------------------------------------------

{
    "command": "Start_Inventory_Thread",
    "params": {
        "timeout_ms": 5000  // 线程运行时间（毫秒）
    }
}

Start_Inventory_Thread 运行在 线程模式，每次检测到新标签时，
都会触发回调 TagProcessingCallback，因此 JSON 需要支持 流式数据推送（如 WebSocket 或 HTTP 长连接）。
每次检测到标签时，返回如下 JSON：
{
    "status": "running",
    "tagCount": 1,  // 每次回调仅返回新检测到的标签数量
    "data": [
        {
            "WAIT_OBJECT": 12347,
            "pTagID": "E2801160600002051890BFC5",
            "tagIDLength": 12,
            "PC": "3000",
            "XPC": "00000003",
            "CRC": "EEFF",
            "antennaID": 3,
            "peakRSSI": -52,
            "tagSeenCount": 1,
            "memoryBank": "EPC",
            "pMemoryBankData": "99AABBCCDDEEFF00112233",
            "memoryBankDataByteOffset": 0,
            "memoryBankDataLength": 12,
            "phaseInfo": 175
        }
    ],
    "timestamp": "2025-02-12T10:10:00Z"
}

当 Stop_Inventory_Thread() 被调用时，返回以下 JSON：
{
    "status": "stopped",
    "message": "Inventory thread stopped successfully",
    "totalTags": 15,  // 线程运行期间读取到的标签总数
    "timestamp": "2025-02-12T10:15:00Z"
}
